# Step Up

Dance studio ops: batches, monthly plans, attendance, retention, booking.

## Apps

| App | Path | Stack | Deploy |
|---|---|---|---|
| Web | `apps/step-up` | React + Vite + `@dev-ui/*` | Cloudflare Pages |
| API | `apps/step-up-api` | NestJS + Prisma + Neon | Cloud Run |

## Local development

```bash
# 1. Tokens (includes step-up Apple-inspired theme)
pnpm build:tokens

# 2. API — copy env, point DATABASE_URL at Neon (or local Postgres)
cp apps/step-up-api/.env.example apps/step-up-api/.env
pnpm --filter @step-up/api prisma:migrate
pnpm --filter @step-up/api prisma:seed
pnpm dev:step-up-api

# 3. Web
cp apps/step-up/.env.example apps/step-up/.env
pnpm dev:step-up
```

Open http://localhost:5180 — use **Continue as** role buttons (`VITE_AUTH_BYPASS=true`).

Dev auth header: `Authorization: Bearer dev:OWNER:owner-1`

## Theme

Built-in `@dev-ui/tokens` theme id `step-up`: soft blue accent, larger radius, SF Pro / Inter stack, light + dark.

## PWA

Step Up ships as an installable Progressive Web App (Cloudflare Pages).

| Piece | Behavior |
|---|---|
| Manifest + icons | Generated by `vite-plugin-pwa` from `vite.config.ts` + `public/icons` |
| Service worker | Precaches the app shell (HTML/JS/CSS). API, Firebase Auth, chat, and R2 media stay network-only |
| Updates | `registerType: "prompt"` — an in-app “Update available / Reload” banner; no mid-session auto-reload |
| Offline | Cached shell loads; banner explains data needs a connection. Login and chat send are disabled offline |
| Install | Chrome/Android: Settings → Install Step Up. iOS Safari: Share → Add to Home Screen |
| Hosting | `public/_redirects` SPA fallback (`/* → /index.html 200`); `public/_headers` keeps `/sw.js` uncached |

Service worker is **off in `vite` dev** (`devOptions.enabled: false`). To debug SW locally, set `devOptions.enabled: true` temporarily and use `vite preview` after a production build.

### Manual QA checklist

- [ ] Lighthouse PWA installable on HTTPS preview
- [ ] Install from Chrome Android / desktop
- [ ] iOS Safari → Add to Home Screen opens standalone
- [ ] Airplane mode → reopen installed app → shell + offline banner
- [ ] Deep link refresh (e.g. `/me/calendar`) returns SPA 200
- [ ] After deploy, update banner appears once; Reload activates new SW

## Deploy

GitHub Actions: [`.github/workflows/step-up-deploy.yml`](../../.github/workflows/step-up-deploy.yml)

Required secrets/vars: Cloudflare Pages, GCP Cloud Run WIF, Neon `DATABASE_URL`, Firebase, R2, Sentry.

Daily jobs: `POST /jobs/daily` with header `x-jobs-secret: $JOBS_SECRET` (Cloud Scheduler).
